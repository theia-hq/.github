# Contributing

Theia's maintainer directs the project and decides what is built. AI agents help write the code and test each
change. In swoosh, its libraries and swoosh-action, each change to the code lands as a pull request and merges once
its CI checks pass.

Outside pull requests are welcome. For a large change, open an issue first.

Report a bug in the issues of the repository it belongs to. Report a vulnerability privately, as
[SECURITY.md](https://github.com/theia-hq/.github/blob/main/SECURITY.md) describes.
