# Theia brand files

| file | what |
| --- | --- |
| `icon.svg`, `icon-white.svg` | the icon, black or white, transparent background |
| `logo.svg`, `logo-white.svg` | the icon and the name, black or white, transparent background |
| `icon-512.png`, `icon-white-512.png` | the icon at 512 px |
| `logo@2x.png`, `logo-white@2x.png` | the icon and the name at 1790 by 410 px |
| `avatar.png`, `avatar-light.png` | the org avatar, 1024 px: the white icon on black, or the black icon on white |
| `favicon.ico`, `favicon-32.png` | the icon at 16, 32 and 48 px |
| `apple-touch-icon.png` | the black icon on white, 180 px |
| `social-card.png`, `social-card-light.png` | 1280 by 640 px link preview, dark or light |

The SVG files are the source; the PNG and ICO files are made from them. The name is set in Roboto Slab Regular.
Greys used with the icon: `#000000`, `#333333`, `#4F4F4F`, `#8D8D8D`, `#FFFFFF`.

What you may and may not do with the name, icon and logo is in the
[brand repository](https://github.com/theia-hq/brand#using-the-name-icon-and-logo).
